PC에서 쓰던 데이터, 모바일에서 로그인하면 보이는가?

2026-07-27 · 개념 Q&A · 드라이브 동기화 v2 배포 기준

Q. 구글 계정을 PC에서 연결해 쓰다가, 다른 모바일 기기에서 로그인하면 자신의 데이터가 연계되어 보이는가?

A. 그렇다. 같은 구글 계정으로 각 기기에서 🔗 구글 계정 연결을 한 번씩만 하면, 두 기기가 같은 드라이브 정본(running_records.json)을 공유해 데이터가 양쪽에 보인다. 기기마다 폴더 지정·파일 선택 같은 별도 설정은 없다.

동작 흐름

[PC]     구글 계정 연결 → 기록 저장 → 몇 초 안에 내 드라이브의
         running_records.json에 자동 업로드
[모바일]  같은 주소 접속 → 같은 구글 계정으로 연결(1회)
         → 앱이 내 드라이브에서 정본을 자동 발견 → 다운로드·병합
         → 대시보드·기록 목록에 PC 데이터가 바로 표시
[이후]    양방향 자동 동기화 — 추가·수정·삭제 모두 상대 기기에 반영
         (수정은 updated_at이 더 최근인 쪽 채택 · 삭제는 부활 방지)

핵심 원리: drive.file 스코프는 "이 앱이 만든 파일"을 앱 단위로 인식한다. PC에서 앱이 만든 정본을 모바일의 같은 앱이 자동으로 찾아내므로 기기 간 연결 작업이 필요 없다. 또한 계정 단위로 격리되어 다른 사용자가 로그인하면 그 사람 자신의 드라이브 데이터만 보인다.

알아둘 예외 · 타이밍

  • 사진은 기기별 보관 — 정본 JSON에 사진은 포함되지 않는다(설계 의도 — 원본 캡쳐는 이미 드라이브에 있고 source_file_id가 연결 고리). 모바일에서 PC 기록은 숫자 데이터로는 완전히 보이지만 썸네일은 없다.
  • 반영 타이밍 — 상대 기기의 변경은 ① 앱을 열고 첫 클릭 시 ② 60초 폴링 ③ 탭 복귀 시 들어온다. "몇 초~1분 내" 수준의 체감 실시간(서버 없는 구조의 의도된 한계).
  • 토큰 만료(약 1시간) — 만료 후 화면을 클릭하는 순간 조용히 재연결된다. 구글 팝업이 잠깐 떴다 닫힐 수 있는데 정상 동작.
  • 첫 접속 시드 기록 — 새 기기 첫 접속 시 예시 기록 1건이 보일 수 있으나, 연결하면 정본과 병합되며 자연스럽게 정리된다(같은 id라 중복 없음, 다른 기기에서 삭제했다면 삭제 반영).
ℹ️ 상세 설계(병합 규칙·tombstone·폴링)는 드라이브 문서 v2 섹션, 계정·자격 개념은 OAuth 개념 문서 참조.
