# 러닝 누적기록 (자동발행)

러닝 앱 캡쳐 이미지를 **데이터화 → 누적 → 대시보드**로 잇는 프로젝트.
지향점은 **제로-DB 플랫폼**: 창작자는 정적 웹앱만 관리하고, **데이터·비용·리스크는 각 사용자 소유**(BYO 스토리지).

## 🏃 메인 앱(index.html) 기능

- **사진 업로드가 기본**: 러닝 앱 캡쳐를 올리면 브라우저 OCR(Tesseract.js)이 거리·페이스·시간·케이던스·고도를 읽어 폼에 채움 → 확인·수정 후 저장. 끌어다 놓기·**클립보드 붙여넣기(Ctrl+V)** 지원, 사진 없이 직접 입력도 가능(오늘 날짜 프리필)
- **영속 저장**: 레코드는 localStorage, 사진은 IndexedDB — 새로고침해도 유지. 정본 백업은 JSON 내보내기/가져오기
- **집계 대시보드**: 링 게이지 달성도(계획 눈금·목표 만점·넛지 카피·요일 도트·계획 연속 주 스트릭) · 꾸준함 잔디(20주) · **올해 누적 거리 vs 계획·목표 페이스라인**(앞섬/뒤처짐 콜아웃) · 주간 거리 차트(기준선) · 페이스 추이 · 누적 통계 · 최근 러닝 (설계: `planning/dashboard-motivation.html`)
- **목표 · 달성도**: **27년까지 2중 관리** — 계획(반드시 지킬 기준, 주황)·목표(도전 기준, 보라) × 주/월/연 × 횟수/거리 + 페이스 기준 2종(안정·기록) + 시작점 환산 → 2중 게이지(눈금=계획·전체=목표) + 페이스 카드 + 이력 테이블 (설계: `planning/dual-goals.html`)
- **데이터 관리**: 기록 표 **검색·월/출처 필터·컬럼 정렬**, JSON 정본 내보내기 + **CSV(엑셀) 내보내기**, JSON 가져오기 **병합(권장)/전체 교체** 선택
- **PWA**: 홈 화면 설치(`manifest.webmanifest` + `sw.js`) · 오프라인 조회(HTML은 network-first, 정적 자산은 cache-first) · 아이콘 재생성은 `scripts/gen-icons.mjs`
- **테마**: 시스템 다크모드 연동 + 토글 선택은 `run.theme.v1`로 저장되어 모든 페이지·재방문에 유지
- **스키마 v2.0**: 칼로리 필드 제거, 고도 상승(elevation_gain_m)·사진 연결(has_image) 추가

## 🧱 제로-DB · BYO 스토리지 모델
```
플랫폼(창작자·정적 웹앱)  →  인증(사용자 OAuth)  →  저장 어댑터(Drive/Local · 스키마 v2.0)
     →  추출(무료 OCR·수동 / 선택 BYOK AI · 사용자 브라우저)  →  대시보드(사용자 데이터셋)
```
데이터는 **사용자 브라우저 ↔ 사용자 저장소**에서만 오가며, 창작자 서버엔 저장되지 않음. (상세: `platform.html`)
