# 러닝 누적기록 (자동발행)

러닝 앱 캡쳐 이미지를 **데이터화 → 누적 → 대시보드**로 잇는 프로젝트.
지향점은 **제로-DB 플랫폼**: 창작자는 정적 웹앱만 관리하고, **데이터·비용·리스크는 각 사용자 소유**(BYO 스토리지).
이 폴더(`C:\Dev\run`)에는 **동작하는 초안 앱**과 **기획/설계 문서**가 정리되어 있습니다.

## 🧪 초안 앱(app.html)에서 할 수 있는 것
- **저장소 연결**: 구글드라이브(추천·실연동 예정)·Notion(준비중)·로컬/데모 — 어댑터 패턴으로 백엔드 교체
- **기록 추가**: ✍️ 수동 입력(페이스↔시간 자동계산) · 🖼️ 이미지 OCR(브라우저) · 📁 JSON 불러오기
- **대시보드**: KPI·주간 거리·페이스 추이·최근 러닝 — **기록에서 실시간 집계**
- **데이터·내보내기**: 표·삭제 · **정본 JSON 내보내기 = 내 저장소에 저장**(데이터는 내 것)

## 🧱 제로-DB · BYO 스토리지 모델
```
플랫폼(창작자·정적 웹앱)  →  인증(사용자 OAuth)  →  저장 어댑터(Drive/Notion/Local · 스키마 v1.0)
     →  추출(무료 OCR·수동 / 선택 BYOK AI · 사용자 브라우저)  →  대시보드(사용자 데이터셋)
```
데이터는 **사용자 브라우저 ↔ 사용자 저장소**에서만 오가며, 창작자 서버엔 저장되지 않음 → **서버·DB 비용 0, 유출 리스크 사용자 위임**. (근거·상세: `platform.html`)
