사용법 · 다음 단계

2026-07-27 · 집계 앱 v2 기준 · 캡쳐 한 장에서 블로그 발행까지

러닝 앱 캡쳐 한 장을 올리면 기록이 누적되고, 저장하는 순간 블로그 글감(제목 + 사진)이 완성됩니다. 데이터는 서버가 아니라 내 브라우저와 내 드라이브에만 저장됩니다.

1. 매일 쓰는 흐름 (3분)

러닝 종료 → 앱 기록 캡쳐
  → [기록 추가]에 캡쳐 올리기 (또는 [드라이브에서 캡쳐 가져오기])
  → OCR이 거리·페이스·시간을 자동으로 채움 → 확인·수정
  → [저장]
  → 블로그 글감 창이 자동으로 뜸
       [🖼 이미지 복사] → [✍ 네이버 글쓰기 열기] → 본문 Ctrl+V → 제목 붙여넣기 → 발행
  → 앱으로 돌아와 [✅ 발행 완료로 표시]
  → 대시보드·목표 달성도에 즉시 반영
ℹ️ OCR은 빈 칸만 채우는 보조 수단입니다. 값이 틀리면 저장 전에 고치세요 — 확인·수정이 정식 경로입니다.

2. 화면별 사용법

화면할 수 있는 일
대시보드링 게이지 달성도·꾸준함 잔디·주간 거리·계획 대비 누적·페이스 추이·최근 러닝
기록 추가캡쳐 업로드(끌어다 놓기 · 붙여넣기 Ctrl+V 가능) → OCR 프리필 → 확인·저장. 사진 없이 직접 입력도 가능(오늘 날짜 자동 입력)
목표 · 달성도계획·목표 2중 기준(횟수·거리·페이스) 설정과 달성률·이력. 기본값은 주 3 · 월 15 · 연 180회
데이터 · 내보내기기록 표(검색·월/출처 필터·컬럼 정렬 · 수정·삭제·블로그 글감), JSON/CSV 내보내기, JSON 가져오기(병합/교체 선택), 드라이브 연동, 블로그 설정

블로그 글감 창

버튼동작
📋 복사제목(26.07.28 - 3.2KM 형식)을 클립보드로
🖼 이미지 복사캡쳐를 클립보드로 (PC — 에디터 본문에 Ctrl+V)
📤 이미지·제목 공유모바일 공유 시트 → 네이버 블로그 앱으로 바로 전달
⬇ 이미지 저장클립보드·공유를 모두 못 쓰는 브라우저용 폴백
✍ 네이버 글쓰기 열기내 블로그 글쓰기 창을 새 탭으로 (카테고리 지정 포함)
✅ 발행 완료로 표시발행 시각을 기록 — 데이터 표에 ✓ 발행 배지, 미발행 목록에서 제외
⚠️ 이미지 복사를 먼저, 글쓰기 창 열기를 나중에 누르세요. 순서가 바뀌면 브라우저가 클립보드 접근을 막습니다(창이 포커스를 가져가기 때문). 두 동작을 한 버튼으로 합치지 않은 이유이기도 합니다.

3. 최초 설정 (각각 1회)

블로그 설정 — 필수

  1. 데이터 · 내보내기 → 네이버 블로그 카드 → ⚙ 설정
  2. 블로그 ID: 블로그 주소의 마지막 부분 (예: blog.naver.com/nevertheless-jos → nevertheless-jos)
  3. 카테고리 번호(선택): 블로그에서 해당 카테고리를 열었을 때 주소의 categoryNo= 값 (예: 운동 → 150)
  4. 기록 저장 후 글감 자동 열기 체크 → 저장

구글드라이브 연동 — 선택

데이터 · 내보내기 → 구글드라이브 → 🔗 구글 계정 연결에서 로그인 한 번이면 끝입니다. 이후 기록을 저장·삭제할 때마다 몇 초 안에 내 드라이브의 정본(running_records.json)에 자동 반영되고, 다른 기기에서 저장한 기록도 이 브라우저로 합쳐집니다. 휴대폰에서 드라이브로 캡쳐를 자동 백업해 두면 📥 캡쳐 가져오기로 여러 장을 골라 순차 처리할 수 있습니다(이미 가져온 캡쳐는 자동 스킵). 상세 설계는 드라이브 문서를 보세요.

ℹ️ 설정값(블로그 ID 등)은 이 브라우저에만 저장되고 서버로 전송되지 않습니다. 드라이브 토큰도 메모리에만 보관됩니다 — 약 1시간 후 만료되면 화면을 한 번 클릭할 때 자동으로 다시 이어집니다.

4. 백업 — 꼭 해두세요

기록은 이 브라우저(localStorage + IndexedDB)에만 있습니다. 브라우저 데이터를 지우면 복구할 수 없습니다.

  • 데이터 · 내보내기 → ⬇ 정본 내보내기(JSON) — 주기적으로 파일로 저장 (사진은 미포함)
  • 구글 계정 연결 — 연결해 두면 저장할 때마다 running_records.json이 내 드라이브에 자동 갱신
  • 복원은 📁 JSON 가져오기 한 번이면 끝 — 병합(권장)은 겹치지 않는 기록만 추가하고, 전체 교체는 파일 내용으로 덮어씁니다.
  • ⬇ CSV(엑셀)는 스프레드시트 분석용입니다 — 백업 정본은 JSON입니다.

5. 홈 화면에 설치 (모바일 앱처럼)

이 앱은 PWA입니다 — 설치하면 아이콘으로 바로 열리고, 오프라인에서도 기록 조회가 됩니다(데이터가 기기에 있으므로).

  • 안드로이드 Chrome: 메뉴(⋮) → 홈 화면에 추가 (또는 주소창의 설치 아이콘)
  • 아이폰 Safari: 공유(□↑) → 홈 화면에 추가
  • 테마(라이트/다크)는 한 번 바꾸면 모든 페이지·재방문에 유지됩니다. 기본은 시스템 설정을 따릅니다.

6. 관리자: 완전 자동 발행 (선택 · 트랙 B)

본인 PC에서 스크립트가 스마트에디터를 직접 조작해 발행까지 자동으로 처리합니다. 브라우저 자동화는 네이버 약관상 회색지대이므로 본인 계정 · 소량으로만 쓰세요. 자세한 리스크는 블로그 문서 §6.

cd scripts
npm install
npx playwright install chromium
node blog-auto-post.mjs --login          # 최초 1회: 창에서 직접 로그인 (자동 입력 없음)

# 앱에서 정본 JSON을 내보낸 뒤
node blog-auto-post.mjs --json ../running_records.json --images ../기록 --blog nevertheless-jos --category 150
    # 기본은 dry-run — 발행 직전에 멈추고 scripts/out/ 에 스크린샷을 남김
node blog-auto-post.mjs ... --publish     # 확인 후 실제 발행 (기본 1건)
⚠️ 첫 실행에서는 스마트에디터 화면 구조가 스크립트의 셀렉터와 다를 수 있습니다. dry-run 스크린샷을 보고 blog-auto-post.mjs 상단의 SEL 값을 맞춘 뒤 --publish를 쓰세요. 발행에 성공하면 JSON에 발행 시각이 기록되고, 그 JSON을 앱으로 가져오면 배지가 반영됩니다.

8. 문제가 생기면

증상해결
글감 창이 저장 후 안 뜬다블로그 ID가 비어 있거나 자동 열기가 꺼져 있습니다. ⚙ 설정 확인. 드라이브로 여러 장을 처리 중일 때는 일부러 뜨지 않고, 다 끝난 뒤 미발행 목록으로 안내합니다.
이미지 복사 버튼이 없다브라우저가 클립보드 이미지를 지원하지 않거나 HTTPS가 아닙니다. ⬇ 이미지 저장으로 내려받아 에디터에서 첨부하세요.
붙여넣기가 안 된다글쓰기 창을 먼저 열었다면 앱으로 돌아와 이미지 복사를 다시 누르고 에디터로 이동하세요.
OCR 값이 자꾸 틀리다캡쳐를 자르지 말고 전체 화면으로, 밝은 테마로 찍으면 인식률이 오릅니다. 그래도 틀리면 직접 수정해 저장하세요.
기록이 사라졌다브라우저 데이터 삭제·시크릿 창·다른 기기입니다. 내보낸 JSON이나 드라이브 백업을 📁 JSON 가져오기로 복원하세요.
드라이브 창이 자꾸 로그인을 묻는다토큰이 약 1시간마다 만료됩니다. 다시 동의하면 됩니다 — 정상 동작입니다.
