러닝 앱 캡쳐 한 장이면,
기록이 알아서 쌓입니다

거리·시간·페이스를 손으로 옮겨 적지 않아도 됩니다. 사진을 올리면 읽어서 채우고, 이번 달·올해 목표까지 얼마나 왔는지 보여줍니다.

지금 시작하기 먼저 사용법 보기
찍어서 올리면 끝

NRC·스트라바 등 러닝 앱 캡쳐를 올리면 거리·시간·페이스를 자동으로 읽어 채웁니다. 틀린 값만 고치고 저장하세요.

목표까지 얼마나 왔는지

주·월·연 목표를 정해두면 달성률이 링으로 보입니다. 꼭 지킬 계획과 도전할 목표, 두 개의 선을 함께 볼 수 있습니다.

내 데이터는 내 것

기록은 내 브라우저와 내 구글드라이브에만 저장됩니다. 운영자 서버에 올라가지 않고, 언제든 파일로 통째로 꺼낼 수 있습니다.

쓰는 법 — 3단계

달리고 난 직후, 폰에서 1분이면 끝납니다.

  1. 캡쳐 올리기

    기록 추가에서 러닝 앱 캡쳐를 고르거나, 끌어다 놓거나, 복사해 온 이미지를 Ctrl+V로 붙여넣으세요.

  2. 숫자 확인하기

    거리·시간·페이스가 자동으로 채워집니다. 맞는지 눈으로 한 번 보고 틀린 칸만 고치세요. 사진 없이 직접 입력해도 됩니다.

  3. 저장하기

    저장하는 순간 대시보드의 누적·목표 달성률에 바로 반영됩니다. 끝입니다.

자동 인식은 빈 칸을 대신 채워주는 보조 수단입니다. 최종 확인은 항상 사람이 합니다 — 저장 전에 한 번만 훑어보세요.

화면 다섯 개가 전부입니다

PC는 왼쪽 메뉴, 폰은 아래쪽 탭바에 있습니다. (폰에서 데이터 · 백업은 더보기 안에 있어요)

대시보드

목표 달성 링, 꾸준함 잔디, 주간 거리, 계획 대비 누적, 페이스 추이.

기록 추가

캡쳐 업로드 → 자동 인식 → 확인 → 저장. 사진 없이 직접 입력도 가능합니다.

목표 · 달성도

주·월·연 기준을 정합니다. 기본값은 주 3회 · 월 15회 · 연 180회.

기록

지금까지 저장한 러닝 목록. 검색·정렬하고 수정하거나 지울 수 있습니다.

데이터 · 백업

파일로 내보내기·가져오기, 구글드라이브·네이버 블로그 연동.

기록을 잃지 않으려면

가장 중요한 한 가지입니다 — 딱 한 번만 해두세요.

기록은 이 브라우저 안에 저장됩니다. 브라우저 데이터를 지우거나 폰을 바꾸면 되돌릴 수 없습니다.
  1. 구글 계정 연결 권장

    데이터 · 백업 → 구글드라이브 → 🔗 구글 계정 연결(또는 기록 추가 화면의 연결 버튼). 로그인 한 번이면 이후 저장할 때마다 내 드라이브에 자동 백업되고, 다른 기기에서도 같은 기록이 이어집니다.

  2. 가끔 파일로 내보내기

    데이터 · 백업 → ⬇ 정본 내보내기(JSON)로 파일 하나를 받아두세요. 복원은 📁 JSON 가져오기 한 번이면 됩니다.

드라이브에는 이 앱이 만든 파일만 접근합니다. 다른 문서·사진은 볼 수 없고, 운영자도 볼 수 없습니다.

폰 홈 화면에 두기

앱처럼 아이콘으로 바로 열립니다. 인터넷이 끊겨도 기록 조회가 됩니다.

안드로이드 Chrome

오른쪽 위 ⋮ → 홈 화면에 추가

네이버 블로그에 올리고 싶다면 선택

기록을 저장하면 블로그 글감(제목 + 사진)이 자동으로 만들어집니다.

  1. 한 번만 설정하기

    데이터 · 백업 → 네이버 블로그 → ⚙ 설정에서 블로그 ID를 넣습니다. 블로그 주소의 마지막 부분이에요 — blog.naver.com/myid 라면 myid.

  2. 저장하면 글감 창이 뜹니다

    🖼 이미지 복사를 먼저 누르고, 그다음 ✍ 네이버 글쓰기 열기. 본문에 붙여넣고 제목을 넣어 발행한 뒤, 앱으로 돌아와 ✅ 발행 완료로 표시를 누르면 됩니다.

순서가 중요합니다 — 이미지 복사가 먼저. 글쓰기 창을 먼저 열면 브라우저가 복사를 막습니다. 폰에서는 📤 공유 버튼으로 블로그 앱에 바로 넘길 수 있습니다.

막힐 때

기록이 사라졌어요

브라우저 데이터를 지웠거나, 시크릿 창이거나, 다른 기기입니다. 내보낸 JSON 파일이나 드라이브 백업을 📁 JSON 가져오기로 되살리세요. 이런 일을 막으려면 구글 계정 연결을 해두는 게 좋습니다.

숫자를 자꾸 잘못 읽어요

캡쳐를 자르지 말고 화면 전체로, 밝은 테마로 찍으면 인식률이 올라갑니다. 그래도 틀리면 직접 고쳐서 저장하세요 — 그게 정상적인 사용법입니다.

이미지 붙여넣기가 안 돼요

글쓰기 창을 먼저 열었다면, 앱으로 돌아와 🖼 이미지 복사를 다시 누른 뒤 에디터로 이동하세요. 브라우저가 복사 기능을 지원하지 않으면 ⬇ 이미지 저장으로 받아서 직접 첨부하면 됩니다.

구글 로그인을 다시 하라고 떠요

보안상 로그인은 약 1시간마다 만료됩니다. 다시 동의하면 됩니다 — 고장이 아닙니다.

저장했는데 블로그 글감 창이 안 떠요

블로그 ID가 비어 있거나 자동 열기가 꺼져 있습니다. ⚙ 설정을 확인하세요. 드라이브에서 캡쳐를 여러 장 처리하는 중에는 일부러 뜨지 않고, 다 끝난 뒤 한꺼번에 안내합니다.

바로 시작해보세요
